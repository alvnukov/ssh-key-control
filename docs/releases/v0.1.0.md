# SSH Key Control 0.1.0

First release for macOS 13 or later. Separate DMGs are provided for Apple Silicon
(`arm64`) and Intel (`x86_64`), with SHA-256 checksums and GitHub build attestations.

- Native menu-bar app, settings and local security history in Russian and English;
  the interface follows the system language.
- SSH key approval tied to the exact key fingerprint, verified server-key
  fingerprint and SSH user. Server names never authorize other server keys.
- One shared duration selector for Allow and Deny: once, 5 minutes, 15 minutes,
  until local midnight, or a custom 1–1440-minute interval. Return follows the
  highlighted action configured in Settings; Escape always denies once.
- Monitoring of Apple's SSH agent is **enabled by default** and can be turned off.
  Detected keys are removed from that agent's memory, with security history and
  macOS notifications. A test-notification button checks notification access.
- Active temporary approvals and denials can be inspected, rescheduled and revoked
  from the menu, without changing their exact key/server/user identity.
- Direct connections from the attested Apple SSH client support verified server
  identification even when the server lacks hostbound authentication.
- Explicit migration of recognized previous SSH-config prefixes with a backup.

## Limits and installation

These DMGs are **ad-hoc signed, not Developer ID signed or notarized by Apple**.
A valid checksum or GitHub attestation does not bypass Gatekeeper. Downloaded
builds may need manual approval in macOS Privacy & Security. The app declares
macOS 13 support; automated native packaging runs on macOS 15 for both architectures.

Open the matching DMG, drag SSH Key Control to Applications, then open the app
and approve its agent setup. Before deleting the app, use Remove Agent Setup.

Unverified SSH destinations permit only one-time decisions. Agent forwarding
is not supported. Monitoring is polling, so a key may be used before detection.
It does not erase private key files or Keychain entries and does not change macOS
protection or Apple's agent startup policy. Software that can read a private key
or its passphrase may bypass an agent. These checks are not a proof of absolute security.

## По-русски

Первый выпуск: приложение в строке меню, настройки и история решений, русский
и английский интерфейс, единый срок разрешения или отказа. Разрешения привязаны
к точному ключу, ключу сервера и SSH-пользователю. Через меню можно просматривать
действующие разрешения и отказы, менять их срок и отменять. Для прямых подключений
штатного SSH-клиента macOS поддерживаются серверы без hostbound: агент проверяет
подлинность клиента и привязку запроса к сессии.

**Мониторинг штатного агента включён по умолчанию:** обнаруженные ключи удаляются
из его памяти, пользователь получает системное уведомление. Галочка отключает
мониторинг. До обнаружения ключ может быть использован. Приватные файлы,
Связка ключей и защита macOS не изменяются.

Сборки подписаны ad hoc, без Developer ID и нотариализации Apple; macOS может
потребовать ручное разрешение открытия. DMG для Apple Silicon и Intel поставляются
отдельно. Для неподтверждённого сервера доступно только одноразовое решение.
